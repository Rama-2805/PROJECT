## Production Notes

### Screen Recording Checklist
- [ ] Clean browser window (no bookmarks, extensions visible)
- [ ] 1920×1080 resolution
- [ ] 60 FPS recording
- [ ] Mute system notifications
- [ ] Use demo mode: `?demo=true`
- [ ] Pre-load all pages
- [ ] Record each scene separately for editing

### Audio
- [ ] Professional voice-over narration
- [ ] Subtle background music (low volume)
- [ ] Sound effects for transitions (subtle whoosh)
- [ ] Text-to-speech option: ElevenLabs or similar

### Editing
- [ ] Smooth transitions (0.5s crossfade)
- [ ] Consistent typography throughout
- [ ] Speed ramps for dashboard interactions
- [ ] End screen with subscribe/visit links

### Tools
- **Screen Recording:** OBS Studio (free) or ScreenFlow
- **Video Editing:** DaVinci Resolve (free) or Adobe Premiere
- **Audio:** Audacity (free) or Adobe Audition
- **Motion Graphics:** After Effects or Manim
